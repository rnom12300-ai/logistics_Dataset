# logistics_Dataset
# تحليل بيانات الشركة العربية للدعم اللوجستي

لوحة تحكم تفاعلية تم بناؤها باستخدام *Power BI* لتحليل أداء مبيعات الشركة العربية للدعم اللوجستي للفترة بين 2020-2024، تهدف لتتبع الإيرادات وأداء الفروع.

![Dashboard Preview](Add%20dashboard%20previe.png)

## الأدوات المستخدمة:
* *Power BI:* لبناء لوحة التحكم وتصور البيانات.
* *Excel:* لإدارة وتنظيف البيانات الخام.
